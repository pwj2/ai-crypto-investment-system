# 数字资产持仓服务 API 接口文档

## 1. 概述

本文档描述了数字资产持仓服务的所有RESTful API接口，包括持仓管理、审核流程、报告管理等功能。

## 2. 基础信息

- 服务地址：`http://localhost:8081`
- API基础路径：`/api`
- 响应格式：JSON

## 3. 持仓管理接口

### 3.1 获取当前持仓

**接口路径：** `/api/holdings/current`
**请求方法：** GET
**功能描述：** 获取当前所有数字资产的持仓信息
**响应格式：**
```json
[
  {
    "id": 1,
    "coinName": "Bitcoin",
    "coinType": "BTC",
    "quantity": 1.5,
    "price": 45000.00,
    "totalValue": 67500.00,
    "proportion": 45.0,
    "updatedTime": "2024-01-01T10:00:00"
  }
]
```

### 3.2 获取历史持仓

**接口路径：** `/api/holdings/history`
**请求方法：** GET
**功能描述：** 获取历史持仓记录
**响应格式：**
```json
[
  {
    "id": 1,
    "coinName": "Bitcoin",
    "coinType": "BTC",
    "quantity": 1.0,
    "price": 40000.00,
    "totalValue": 40000.00,
    "proportion": 40.0,
    "updatedTime": "2023-12-31T10:00:00"
  }
]
```

### 3.3 更新持仓

**接口路径：** `/api/holdings/update`
**请求方法：** POST
**功能描述：** 批量更新持仓信息（需审核通过后调用）
**请求体：**
```json
[
  {
    "coinName": "Bitcoin",
    "coinType": "BTC",
    "quantity": 1.5,
    "price": 45000.00
  }
]
```
**响应格式：**
```json
"持仓更新成功"
```

### 3.4 根据ID获取持仓详情

**接口路径：** `/api/holdings/{id}`
**请求方法：** GET
**功能描述：** 根据ID查询特定资产的持仓信息
**响应格式：**
```json
{
  "id": 1,
  "coinName": "Bitcoin",
  "coinType": "BTC",
  "quantity": 1.5,
  "price": 45000.00,
  "totalValue": 67500.00,
  "proportion": 45.0,
  "updatedTime": "2024-01-01T10:00:00"
}
```

## 4. 审核管理接口

### 4.1 审核通过

**接口路径：** `/api/reviews/pass/{reportId}`
**请求方法：** POST
**功能描述：** 审核通过建议报告，更新持仓信息
**路径参数：** 
- `reportId`: 报告ID
**响应格式：**
```json
{
  "code": 0,
  "msg": null,
  "data": "审核通过，持仓已更新"
}
```

### 4.2 审核驳回

**接口路径：** `/api/reviews/reject/{reportId}`
**请求方法：** POST
**功能描述：** 审核驳回建议报告
**路径参数：** 
- `reportId`: 报告ID
**查询参数：**
- `reason`: 驳回原因
**响应格式：**
```json
{
  "code": 0,
  "msg": null,
  "data": "审核驳回"
}
```

## 8. 响应状态码说明

| 状态码 | 含义 | 说明 |
|-------|------|------|
| 0     | 成功 | 操作成功 |
| 1     | 失败 | 操作失败 |
| 400   | 错误请求 | 请求参数错误或格式不符合要求 |
| 404   | 未找到 | 请求的资源不存在 |
| 500   | 服务器错误 | 服务器内部错误 |

## 9. 错误处理

所有API接口在遇到错误时，将返回统一的错误格式：

```json
{
  "code": 错误码,
  "msg": "错误描述",
  "data": null
}
```

## 10. 安全说明

- 所有API接口需要进行身份验证
- 敏感操作需要管理员权限
- 请确保使用HTTPS协议进行传输
